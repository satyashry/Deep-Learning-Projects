# Rice Leaf Disease Classification using CNN

A deep learning project that classifies rice leaf diseases from leaf images using Convolutional Neural Networks (CNNs). The goal is to assist in the early detection of crop diseases, enabling timely intervention and reducing yield loss.

## Problem Statement

Rice is one of the world's most important staple crops. Leaf diseases can significantly impact crop quality and production if not detected early. Manual disease identification is time-consuming and requires expert knowledge.

This project develops a CNN-based image classification model capable of automatically identifying different rice leaf diseases from leaf images.

## Objectives

- Perform Exploratory Data Analysis (EDA) on the dataset.
- Preprocess image data for model training.
- Apply data augmentation techniques to improve model generalization.
- Train and evaluate multiple CNN models.
- Compare model performance using evaluation metrics.
- Select the best-performing model for deployment.
